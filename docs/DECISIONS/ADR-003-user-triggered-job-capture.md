# ADR-003：岗位采集必须由用户主动触发

- **Status**：Accepted
- **Date**：2026-08-30

## Context

JobPilot 需要跨招聘平台保存岗位，但不替代招聘网站，也不建立批量职位数据库。招聘平台页面结构会变化，并涉及登录、反自动化、服务条款、用户隐私和服务器负载风险。

## Decision

浏览器扩展只处理用户当前已经主动打开的具体岗位详情页：

```text
用户点击 -> 当前页面 DOM 解析 -> 用户确认 -> JobPilot API 保存
```

自动解析失败时，按顺序提供手动选择页面内容和手动粘贴 JD。平台差异封装在独立 `JobSiteAdapter` 中，统一产出 `JobCapture`。

明确禁止后台批量爬虫、自动翻页、职位列表扫描、验证码或登录绕过、隐藏接口批量采集、高频平台请求以及未经用户触发的数据采集。

## Consequences

- 采集范围更可解释，符合 JobPilot 的辅助工作台定位。
- 用户确认能修正解析错误并减少错误数据进入业务库。
- 扩展无法提供“全网自动同步”，这是有意接受的产品边界。
- Adapter 会随平台 DOM 变化而维护，必须用脱敏 HTML fixtures 做回归测试。
- Content Script 保持无业务状态、无持久化规则和无后台抓取能力。
- 平台条款与页面变化仍需持续评估；技术限制不等同于法律结论。
